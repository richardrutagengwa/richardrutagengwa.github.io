EVENTS PORTFOLIO v2 — SIMPLE UPLOAD

This update changes the large Events block into a scalable event-card gallery.
It also adds a dedicated event page for the Comoros REV & MEV Training of Trainers.

1. In GitHub repository richardrutagengwa.github.io:
   Add file → Upload files

2. Upload/replace these at the ROOT:
   - index.html
   - style.css
   - sitemap.xml
   - robots.txt

3. Upload the new folder:
   events/
     comoros-rev-mev-tot.html

4. Keep the existing photos under:
   assets/events/comoros-rev-mev-tot/

5. Commit message:
   Upgrade Events portfolio and add Comoros event page

6. After Pages deployment is green, open:
   https://richardrutagengwa.github.io/?v=events2

7. Click:
   Events → View event & photos

The event detail page should open at:
https://richardrutagengwa.github.io/events/comoros-rev-mev-tot.html
