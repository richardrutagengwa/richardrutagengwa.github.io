# Richard Niragire Rutagengwa — Digital Health Portfolio

Professional personal website for Richard Niragire Rutagengwa.

## Publish with GitHub Pages

1. Upload all files and folders in this package to the root of:
   `niragire-rutagengwa-richard.github.io`
2. Open repository **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Visit:
   `https://niragire-rutagengwa-richard.github.io`

## Important edit

When your final LinkedIn public URL is ready, add it:
- in the contact section of `index.html`
- in the `sameAs` array inside the JSON-LD block

## Security and privacy

Do not upload:
- passwords, API tokens or login credentials
- national ID or full home address
- patient data
- confidential project reports or client screenshots
