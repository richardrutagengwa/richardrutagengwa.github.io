## GitHub Pages deployment

The site is published from the `main` branch at the repository root.

To update the website:
1. Edit the relevant files in this repository.
2. Commit changes to `main` (or merge a reviewed pull request).
3. Allow GitHub Pages a short time to publish the update.
4. Check the live website on desktop and mobile.

## Main files

- `index.html` — page content, metadata, project and contact sections.
- `style.css` — responsive layout and visual styling.
- `script.js` — mobile navigation, reveal effects and footer year.
- `assets/` — public portrait and event imagery. The CV is intentionally not hosted in this public repository; request access by email.
- `events/` — detailed event pages.

## Contact form

The contact form uses FormSubmit and sends submissions to the portfolio email address configured in `index.html`. The recipient must complete FormSubmit's first-use activation email before submissions can be delivered.

## CV access and security

The CV is intentionally excluded from the public website and repository. Visitors can request access by emailing `rrutagengwa@gmail.com`; share the CV separately using a restricted-access service and grant access only to approved recipients.

Do not upload passwords, API tokens, national ID numbers, patient data, confidential project reports or client screenshots.
